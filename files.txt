【サイトファイル一覧】
小牧市東部（篠岡地区）学校再編計画 市民情報サイト
生成日：2026-05-24
======================================================

■ HTMLページ
index.html          サイトのトップページ。計画概要・現在の状況・今後のスケジュールをまとめたホーム画面。下部の「最新の動き」以降は毎日自動更新されるコーナー。
about.html          学校再編計画の背景・目的・対象校・新校名などを詳しく解説する計画概要ページ。
schedule.html       フェーズ別タイムライン・月別カレンダー・主要イベント一覧を掲載するスケジュールページ。
council.html        市議会での審議内容（令和8年第1回定例会）を整理した議会審議ページ。
community.html      地域協議会・区長会への報告経緯と住民意見をまとめた地域協議会ページ。
voices.html         再編計画に対する賛成・反対・中立の住民意見をカード形式で紹介するページ。
faq.html            よくある質問と回答をアコーディオン形式で提供するFAQページ。
bus.html            スクールバスの運行予定・対象校・費用負担などを解説するスクールバス情報ページ。
map.html            再編対象の各学校の位置を地図で確認できる学校マップページ。
nationwide.html     全国の廃校数・国が示す学校規模と通学の基準・2026年8月の手引改訂を整理した「全国の動き」ページ。
review.html         計画の検証と提案のページ。公表資料から確認できること・できないことを整理し、地区全体の児童生徒数を増やす方策を検討する。当サイトの見解を含む唯一のページ。

■ スタイル
css/style.css       サイト全体のデザイン・レイアウト・カラー・レスポンシブ対応を定義するスタイルシート。共有ボタン（.share-*）もここ。

■ JavaScript
js/i18n.js          言語JSONファイルを非同期取得してページ内テキストを多言語に切り替える国際化スクリプト。
js/main.js          ハンバーガーメニュー・カレンダー・日付自動ステータス更新・公式ニュース表示・共有ボタン（SNS＋はてな）などのUIロジックを担うメインスクリプト。

■ データ
data/news.json              GitHub Actionsが定期取得した市公式サイトの最新お知らせを格納するJSONファイル。
data/official_pages/        市公式サイト各記事ページの本文テキストスナップショット（自動生成・手編集不可）。git diffで本文変更を検知するために使用。
                            303-* は学校再編（教育総務課）、sasaeai-3-3_2-* は地域協議会（支え合い協働推進課）の監視専用ページ。
data/events.json            カレンダーイベントデータ（日付キー＋10言語ラベル）。schedule.htmlのカレンダーが実行時にfetchして描画。イベントの追加・変更はこのファイルを編集する。
data/site-facts.json        公式ページのスラッグとサイト内反映箇所の対応表（手動管理）。更新検知Issueに「更新候補箇所」を載せるために使用。
data/school_news.json       再編対象8校の公式ホームページ新着記事（自動生成・手編集不可）。トップページのコーナーが実行時にfetchして描画。
data/community_events.json  地域協議会イベント案内（自動生成・手編集不可）。community.htmlのコーナーが実行時にfetchして描画。
                            市サーバへは行かず、official_pages/のスナップショットから組み立てる。篠岡地区の5協議会分はshinooka=trueで先頭表示。
data/chunichi_news.json     中日新聞Webの小牧市東部（篠岡地区）関連記事（自動生成・手編集不可）。トップページの「報道でみる東部地域」が実行時にfetchして描画。
                            見出し・掲載日・記事URL・冒頭1文の引用のみを保持する。checked_idsは確認済み記事IDの記録で、同じ記事を二度取りに行かないためのもの。
data/site-updates.json      このサイト自身の更新履歴（手動管理）。トップページ最下部の「サイトの更新履歴」が実行時にfetchして描画。新しいものを配列の先頭に追加する。
data/bus_area.geojson       スクールバス通学対象エリアのポリゴン（手動生成）。市教委「学校再編だより」vol.6の対象エリア図を目視トレースし、図中の500mスケールバーと2校の位置注記で座標を合わせた非公式の近似図。bus.htmlの地図がfetchして描画。正式な対象可否は市の送付書類による。
data/bus_area.kml           上記と同じ図形のKML版。Googleマイマップに読み込んでGoogleマップ上に重ねるためのもの。bus.htmlからダウンロードリンクを張っている。
data/bus_map.geojson        bus.htmlの地図が描画する全データ（手動生成）。対象エリア・通学区域（桃花台東/西）は「学校再編だより」vol.6の図を目視トレースした非公式の近似。道路・地区名・施設はOpenStreetMap（ODbL、出典表示が必要）。層ごとにlayer/catプロパティを持ち、js/main.jsがチェックボックスで表示を切り替える。
data/community_actions.json 閉校を惜しむ市民有志の取組（手動管理）。community.html「地域の取組」（地域協議会イベント案内の直下）が実行時にfetchして描画。市の公式情報でも報道でもなく市民有志の発信であり、計画の内容・数値の根拠には使わない。source_urlはauto_gates.pyのPERMITTED_INSTAGRAMにあるアカウントのみ。
data/i18n/ja.json           日本語（デフォルト言語）の翻訳テキストをすべて格納する言語ファイル。
data/i18n/en.json           英語の翻訳テキストを格納する言語ファイル。
data/i18n/pt.json           ポルトガル語（ブラジル）の翻訳テキストを格納する言語ファイル。
data/i18n/vi.json           ベトナム語の翻訳テキストを格納する言語ファイル。
data/i18n/tl.json           フィリピノ語（タガログ語）の翻訳テキストを格納する言語ファイル。
data/i18n/es.json           スペイン語の翻訳テキストを格納する言語ファイル。
data/i18n/zh.json           中国語（簡体字）の翻訳テキストを格納する言語ファイル。
data/i18n/id.json           インドネシア語の翻訳テキストを格納する言語ファイル。
data/i18n/tr.json           トルコ語の翻訳テキストを格納する言語ファイル。
data/i18n/my.json           ビルマ語の翻訳テキストを格納する言語ファイル。
data/i18n/ja-kids.json      「こどもむけ」モード用の上書き辞書。小学3年生レベルのやさしい日本語でja.jsonのキーを上書きする。

■ ページ別辞書（自動生成）
data/i18n/pages/            各ページが実際に使うキーだけを切り出した辞書（<ページID>.<言語>.json、110ファイル）。
                            .github/scripts/build_community_events.py  地域協議会イベント案内をスナップショットから抽出してcommunity_events.jsonを生成するスクリプト。市サーバへのアクセスなし。
.github/scripts/build_page_dicts.py が生成する。手編集不可。
                            i18n.js はこちらを優先して取得し、404 のときだけ全体辞書に落ちる。

■ 検索エンジン向け
robots.txt                  クローラ向けの許可設定とサイトマップの所在。全ページ許可。
sitemap.xml                 全10ページのサイトマップ。各URLに10言語＋x-defaultのhreflang相互参照を付与。
                            手動管理のため、ページを追加・削除したらここも更新すること。

■ GitHub Actions
.github/workflows/fetch-news.yml    市公式サイトから最新お知らせを定期取得してnews.jsonと本文スナップショットを更新し、本文変更時はIssue起票→AIによる修正案の起案→機械検証→監査AI→自動マージまで行うワークフロー定義。
.github/scripts/fetch_news.py       市公式サイトをスクレイピングしてお知らせ情報の抽出・整形と各ページ本文のスナップショット保存を行うPythonスクリプト。
.github/scripts/fetch_schools.py    再編対象8校のホームページ（komaki-aic.ed.jp）を巡回し、各校の最新記事をschool_news.jsonに保存するスクリプト。
.github/scripts/fetch_chunichi.py   中日新聞Webの小牧市エリア一覧を巡回し、東部（篠岡地区）に関する記事の見出し・日付・冒頭1文をchunichi_news.jsonに保存するスクリプト。地名で判定する。
.github/scripts/map_targets.py      変更された公式ページのスラッグをsite-facts.jsonで引き、サイト内の更新候補箇所をMarkdown出力するスクリプト（Issue本文生成用）。
.github/scripts/build_page_dicts.py  data/i18n/pages/ を生成する。辞書やHTMLのdata-i18nを変えたら実行してコミットすること。--check で鮮度検証のみ。
.github/scripts/auto_gates.py       自動更新のガードレール検証（編集範囲・スキーマ・ja/enキー一致・こどもモード1行の長さ・ページ別辞書の鮮度・外部リンク規則・出典実在チェック）。exit 0=合格/3=変更なし/1=不合格。
.github/scripts/auto_report.py      自動更新のPR本文・事後報告コメントをevidence.json/verdict.jsonから生成するスクリプト。

■ 設定・その他

CONTRIBUTING.txt               コンテンツ管理チェックリスト。外部リンク制限・i18nルール・日付連動の自動表示・こどもむけ等の運用ルールと検証手順を記載。
README.md                      プロジェクト概要・ページ構成・対応言語・ローカル開発手順を説明する公開用READMEファイル。
CLAUDE.md                      Claude Code向けの開発ガイド（英語）。i18n仕様・検証コマンド・制約事項を記載。
CLAUDE_ja.md                   CLAUDE.mdの日本語説明ファイル。日本語話者向けにCLAUDE.mdの内容を解説。
files.txt                      本ファイル。サイト構成ファイルの一覧と説明を手動管理するインデックス。
