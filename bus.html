スクールバス計画

令和9年度（2027年度）の学校再編に合わせて、通学距離が遠くなる小学生を対象にスクールバスが導入されます。市が全額負担のため、児童は無料で利用できます。

計画のポイントKey Facts

スクールバス計画の骨格となる3点です。対象エリア・安全対策・申請方法など詳細は、以下の各セクションをご覧ください。

小学生
対象（中学生は自転車）
無料
市が全額負担
R9年4月
本格運行開始予定

運行の概要Overview

📅

運行日

学校の登校日に運行。長期休暇中は運休しますが、運動会や出校日などの学校行事がある場合は運行します。

🚌

便数

登校：1便（全学年）
下校：最大3便（低学年・高学年・部活動日用）

💴

費用

児童は無料で利用できます。学校再編によって通学距離が遠くなる点を考慮し、市が全額負担します。

🚐

車両と台数

2校合計で5〜6台程度。定員28名（運転手を除く）のマイクロバス（横幅約2.1m×全長約7m）を想定しています。

📋

申請制

対象エリア内の児童の希望申請を受け付けます。毎年、バスの定員・通学団の編成状況をふまえながら決定します。

対象エリアService Area

エリアの基準

スクールバスの対象エリアは、通学距離が2km以上となる児童に加え、篠岡地区の地域の特性（学校までの高低差等）に配慮したエリアを設定します。

対象地区（計画案）

🏫

桃花台東小学校 通学区域

池之内・林・野口・大山・大草 各地区

🏫

桃花台西小学校 通学区域

上末・下末・高根 各地区

※ エリア外の児童でも、最寄りの通学団が著しく遠く集団での登下校が困難な場合は、教育委員会よりスクールバス利用の提案を受けることがあります。

申請の手続きHow to Apply

📮 書類の提出期限
令和8年（2026年）8月30日 〜 9月30日
スクールバスを希望する・しないに関わらず、書類の返送が必要です。
✉️

書類が届いた人

対象エリア内の児童の保護者あてに、申請書類と説明会の案内が市から郵送されています。届いていない場合は、教育総務課へお問い合わせください。

↩️

全員が返送

利用を希望しない場合も返送が必要です。返送がないと、市が利用希望の有無を把握できません。

🗣️

説明会（希望者）

利用を希望する方は説明会への参加が求められています。乗降場所・運行ダイヤ・「スクールバス利用ガイドライン」が配布・説明される予定です。

💬

相談会

説明会のなかで、バス利用について気になることや不安なことを相談できる「相談会」も実施される予定です。

出典：小牧市教育委員会 教育総務課『篠岡地区 学校再編だより』vol.6（令和8年8月）

バス停と乗降場所Bus Stops

バス停は、児童が安全に待機・乗降できる地域の会館や公共用地等が指定されます。バスの定時性を確保するため、箇所数は絞る考えが示されています。

地区 バス停の数（想定） コース数（案）
桃花台西5〜6箇所3コース
桃花台東9〜10箇所4コース
⚠️ 以下のバス停は「だより vol.3」時点の案で、現在見直しが進んでいます。 vol.4 では、実際にバスを走らせて乗り降りのしやすさ・待機スペース・運行ルートを確認する作業を進めており、課題の洗い出しを経て改めてバス停（案）を示すと説明されています。確定した乗降場所と運行ダイヤは、対象者向けの説明会で配布されます。

桃花台西のコース案

  1. コース1上末八幡緑地 → 陶小学校 → 現.桃ヶ丘小学校 → 陶小学校 → 現.桃ヶ丘小学校
  2. コース2下末会館北側 → 勤労センター → 現.桃ヶ丘小学校 → 下末会館北側 → 現.桃ヶ丘小学校
  3. コース3大草会館 → 現.光ヶ丘小学校 → 高根会館前 → 現.桃ヶ丘小学校

桃花台東のコース案

  1. コース1赤坂児童遊園 → 池之内会館 → 現.光ヶ丘小学校 → 池之内川南集会所 → 現.光ヶ丘小学校
  2. コース2林会館 → 現.光ヶ丘小学校 → 林会館 → 野口会館 → 現.光ヶ丘小学校
  3. コース3大草会館 → 現.光ヶ丘小学校 → 高根会館前 → 現.桃ヶ丘小学校
  4. コース4四季の森前 → 老人憩の家 → 愛知文教大学前 → 現.光ヶ丘小学校 → 大草会館 → 現.光ヶ丘小学校

地名・施設名は市の資料の表記のまま載せています。斜体が降車先の学校です。1台のバスが学校へ着いたあと、別のバス停へ戻ってもう一度運ぶコースも含まれています。

🕗 学校への到着は7時50分〜8時15分の間を想定。下校は5限後・6限後・部活動後の最大3便が想定されています。

学校の敷地内での乗降場所

🏫

桃花台東小（現・光ヶ丘小学校）

東側駐車場。東門から進入し、敷地内で転回して東門から出ます。登校時は玄関付近に縦列（最大2台程度）、下校時は横並びでの停車を想定しています。

🏫

桃花台西小（現・桃ヶ丘小学校）

北側駐車場。現在使っていない西門から進入し、敷地内で転回して西門から出る（または北門から西門への一方通行）ことを想定。登下校とも渡り廊下付近または北側昇降口付近での停車を想定しています。

出典：『篠岡地区 学校再編だより』vol.3・vol.4（小牧市教育委員会 教育総務課）

安全対策Safety Measures

🔔

乗降確認システム

児童がスクールバスに乗ったかどうかを、保護者や学校がリアルタイムで確認できるシステムを導入します。

🛡️

置き去り防止システム

バスへの置き去りを防止するためのシステムを導入し、乗車後の安全確認を徹底します。

👨‍✈️

添乗員

保護者の不安解消と児童の安全・安心を最優先に、すべてのバスに添乗員を配置する方針が示されています。事業者に業務委託した添乗員が同乗し、マニュアルに基づく事前研修を受けた人材が担当します。
